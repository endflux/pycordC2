# pycordC2
this is a minimal "c2" framework that uses discord as the server the agent  uses only bit in libs making outbound requests to your discord servers widget and web hook 

# set up
- make a server and turn on widget in server settings > engagement > scroll down to the bottom of the page 
- make webhook in server setting > integration > add webhook
- make bot in 0auth2 
add all that shit to the env
# use 
- run pycordC2.py in terminal you interact with the bot enter from there
